# Changelog

## v1.0.0 (2026-11-09)

First release.

- 50 niches for an AI SDR business, each with the buyer, who the booked calls are with, why they would pay, a ready offer, an opening message, where to find leads, what to avoid, and a score on each of 7 criteria.
- A published rubric with written meanings for the scores, and a leaderboard and 50 niche cards generated from the data.
- 16 regulated niches (health, finance, legal), each with a compliance note.
- `tools/rank.py`, a standard library Python tool that applies your weights, experience and country, and prints your ranking.
- A paste in Claude Code quick start prompt, a Claude Code skill and a `/pick-niche` command that re score the 50 and pick your top 3.
- A pick your niche worksheet, 4 guides, 3 worked examples with invented people, and a synthetic sample lead sheet.
- `tests/check_kit.py`, and a GitHub Actions workflow that runs it on every push.
- Product and rule facts checked on 2026-11-09, listed in `SOURCES.md`.
